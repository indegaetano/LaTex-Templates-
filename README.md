# LaTex Templates
Check out the various LaTex templates I have made for assignments and exams for various classes I have taught in the past. 

### How to Use: 
To use any of these templates, simply copy and paste the code into an empty LaTex file. Don't have LaTex? Use Overleaf, an online browser based code renderer for LaTex. Copy and paste the code into there, recompile, and boom! you have a wonderful typeset math document. 
Or, you can download the files as tex files and upload them into Overleaf to complile.
